## A. What "finished" means to the owner
ForeverRoute must become a genuinely PLAYABLE, RELIABLE 1–60 step-by-step quest leveling guide, not merely a set of reports, test JSON files, generated sections or a pass-rate dashboard. It must cover genuinely obtainable Forever quests, quest chains, class-specific tasks, quest giver/objective/turn-in positions, transport, hearthstone, flight points, zone transitions and newly opened Mount Hyjal. Optimize for useful leveling speed, route legality, travel and XP, never at the expense of mandatory quest/class eligibility or player progress.

For every supported profile, the shipped effective guide must correctly recommend available quests, automatically adapt after accept/complete/abandon/reacquire, maintain no-dead-end sequencing across bands 1–60, handle multiple quest pickups/turn-ins per NPC, guide the player with NOW / NEXT / PREVIOUS / GUIDE / ON THE WAY, map/minimap pins and arrows, and preserve character-specific SavedVariables on reload and switching planners.

The addon is already a public BETA. This charter targets a truly completed production-ready 1–60 experience; it does not retroactively declare existing beta complete, nor authorize automatic publication.

## C. Uncompromisable acceptance rules

- Distinguish "files exist", "data sourced", "route compiles", "simulator passes", "in-client observed", "public released". Only verifiable production output satisfies DONE.
- Independent reproducible tests for all 56 supported race/class profiles, both factions, 13 bands and V3+V4. Never report 100% guide/waypoint completeness from structure alone. Gate on missing objectives, wrong NPCs, reversed prerequisites, quest masks, level and class restrictions, no false arrows, no silent step loss, no critical route dead end. A malformed or missing test artifact is NOT a passed test.
- Apply prior T148 policy: >=80% evidence coverage PER PROFILE (not fleet average), missing facts remain amber, blocked stays blocked; goal of very high coordinate precision remains long-term and is not a reason to stall a playable beta. Preserve documented waivers as review items, not automatic passes.
- Owner-approved constraint: new quest recommendations must respect questLevel <= playerLevel+2; already accepted/deferred class chains must remain intact. Do not drop mandatory class quests; no dungeon-only recommendation for solo play, no false XP catch-up, no unnecessary six-quest cap.
- A waypoint is accepted as coordinate evidence only when Forever-specific provenance establishes role (NPC pickup vs objective vs turnin vs merely player's location), uiMapID/x/y validity, questID/objective identifier and build. +/-3 yards is an arrival radius, NOT proof of positional accuracy. Mark all source ambiguity; prefer safe fallback to deceptive precise pin.
- Validate runtime regressions q376, q91208, Paladin chain, class Hunter/Warlock/Druid/Shaman/Paladin, same-NPC batching, cross-zone routing, accepts while in combat, wrong NPC recommendations, 0,0 pin, skip/back, nameplate/tooltip/actionbar taint, map zoom/arrow sync, event/performance spikes, SavedVariables reload/logout and Planner V3/V4 switching.
- Fix root causes in source/generator + tests, not by altering only generated output. Preserve reproducibility, before/after diffs and rollback. Both V3 and V4 must be tested against exactly the shipped Lua, not just a desired compiler output.
- Protect DB/forever/quest.lua and DB/forever/xp.lua; never bypass the user's prohibitions. No changes to installed WoW, SavedVariables, Jarvis 1.0, protected GUI-owned ForeverRoute worktrees or Blizzard namespace. No unauthorized network scrapes or copies of proprietary paid guides, no release/push/merge, no bypassing T81/T45/T148 safety holds.
- Optional Quest Atlas, Guide Me, UI cosmetics and monetization follow the core playable 1-60 route unless necessary for basic navigation.
